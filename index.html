    Danger zone

    Save from any page

    Drag this button to your bookmarks bar:

    + Linkshelf

    Click it on any page to save that page here, with its title as the name. Any text you've selected on the page becomes the note.

    Other quick ways to add

    • Paste anywhere. Copy a URL, click the page, press ⌘V. Several URLs at once work too.
    • Drag in. Drag a link or the address-bar icon from another window and drop it on a heading.
    • Type it. The add bar takes url or url some name.
